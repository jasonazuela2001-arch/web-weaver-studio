# AI Automation Portfolio

## Goal
Build a polished single-page portfolio for an AI automation expert, focused on helping prospects understand the service and start a conversation.

## Page structure
- Fixed, minimal navigation linking to Home, About, Skills, Experience, and Contact
- Opening section with a clear positioning statement, contact call-to-action, and animated automation blueprint artwork
- About section explaining the workflow-first approach and client value
- Skills section covering workflow design, AI integration, system connections, and optimization
- Experience section presented as a concise project and capability timeline
- Contact section with direct email action and a compact project inquiry form

## Visual direction
- Light, minimal design using Inter throughout
- Neutral white and cool-gray surfaces with accessible blue brand accents
- Blueprint grid, connected nodes, rotating gears, and moving workflow paths as subtle visual motifs
- Restrained entrance and scroll animations, with reduced-motion support
- Responsive layouts tuned for phone, tablet, and wide desktop screens

## Technical details
- Implement within the existing TanStack single-page project at `/`
- Keep styling centralized in the project design system using semantic color and motion tokens
- Use CSS animations rather than external scripts to preserve performance and framework compatibility
- Add route-specific title, description, Open Graph, and Twitter metadata
- Verify the final page visually at desktop and mobile sizes and confirm the preview reports no errors
